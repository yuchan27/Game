## Player rules and implementation owners

`quests.json` selects the relay at `[.415,.675]` and the isolator at `[.65,.37]`,
near actual pumphouse/furnace structures and away from story walkups and guarded
site labels. Wasteland places a map-event marker, state label and active-contract
interaction. E prompts follow the actual device bounds. Returning to the route
reads the existing `route_states[route].field_objectives` completion flag.
World status text is shown only within 280 world pixels; distant devices keep
their map markers, avoiding clipped labels at the viewport edge.

New rescue/sabotage acceptances carry the optional version marker in existing
`quest_progress`. Those contracts require the field action as well as their
existing defeat/material goals. An older active save without the marker keeps
the previous completion rule, while still allowing the optional action. Already
completed legacy quests display a closed status instead of suggesting they can
be accepted again. IDs, rewards, save version and Base64/SHA-256 wrapper remain.

GameState rejects action calls from the wrong contract, scene or route, repeated
completion, zero HP or pending death. Optional nested field-state data must be a
map of nonempty string keys to Boolean values when loading. The action emits UI
updates and saves once; it grants no separate items/XP. Existing village/guild
hand-in owns rewards and resource consumption.

Factory sabotage lowers the future normal-enemy refill cap by six. Existing
enemies remain, and Boss encounter rules are unchanged. The relay's result is a
local rescue-communication repair; it does not complete the village water arc.
J puts the active contract first and includes the full field description. The
compact HUD uses a short target/E/M/J hint.

## Production evidence boundary

The initial ordinary art frames exposed detached context groups and a factory
objective overlapping a guarded-site label. Both placements were revised before
final review. Pending and completed **art states are deliberately staged** by the
preview recipe; those images do not prove action execution, save compatibility,
repeat guards, reward distribution or encounter traversal. QA/test suites remain
deferred by the user's current instruction. See the current capture checkpoint
at `captures/chapter-sites/` for actual rendered composition and the remaining
validation requirements.
