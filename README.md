# 廢土回收商 Wasteland Recycler

Godot 4.6.3 製作的 PC 像素風偽 3D 單機遊戲。目標為劇情出征型 Roguelite；
目前已在原始碼接入 v5 出征收穫與返村門結算，以及本趟戰地調校；尚未完成遊戲流程、存檔或平衡驗收。
新旅程的野外收穫先留在本趟背包；成功由返村門抵達後才入庫，死亡會失去本趟
收穫及暫存的任務／現場進度。已入庫物資、經驗與等級、擊殺紀錄、已發現紀行線索
仍保留。操作騎士機體 R-17，在村莊整備、公會接委託，前往六個廢土區域戰鬥、
回收並調查撤離紀錄，返回村莊交付任務、合成、升級並保存進度。每趟在所選路線
前兩個既有探索點可各選一次戰地調校，三種方案能重複或混搭，效果只在本趟加到
既有能力；死亡或成功撤離後清除，不花新貨幣、不重抽也不改永久能力。十二趟
主線行動已接入原始碼，完整旅程尚未遊玩驗收，時間目標也未經測量。

本篇主線「灰燼之後的名字」從村莊的供水危機開始，沿廢鐵公路、毒沼、
紫晶裂隙、舊工廠，追到都心名冊與地下保存艙。艾倫一開始便認出曾撐門救人的 R-17；
調查要回答的是當年為何封鎖外圍水路、今天如何安全復水。每區有固定調查地標；開 M
找橘色事件標記，靠近按 E 閱讀。K 手記保存已發現的內容與下一步。
完成前四份核心委託後，J 會解鎖都心調查，再接地下設施終章；兩份舊支線仍可承接。
第一份新承接的公路委託先護送回收隊、按住 E 接線，另趟選路搬運接頭；
兩趟步驟安全帶回、原本擊敗與廢鐵目標都達成後才回村按 J 一次交付。舊存檔已承接但無版本標記的委託，
保留原有條件。首次主線交付後，村莊蓄水槽出現臨時細流；終章交付後才有穩定而有限的
供水。兩階段都仍需配給，沒有隱藏缺水倒數。這些是已接入的原始碼內容，尚未走完整流程驗收。
v1–v4 舊存檔若在野外載入，第一次返村前沿用原本物資立即入庫的規則；新版出征中彈藥
優先消耗本趟收穫，已使用的庫存彈藥不會因死亡退還。合成、拆解、治療與永久升級需在村莊或公會進行。

[舊版出征介面呈現紀錄](docs/expedition-presentation/README.md) 保存戰地調校接入前的 18 張手動配置畫面與來源雜湊，
現為歷史快照；[戰地調校歷史畫面紀錄](docs/draft-presentation/README.md) 則記錄兩種視窗尺寸下的 14 張手動配置畫面。
這些紀錄只涵蓋畫面呈現，不代表實際選擇、戰鬥、任務結算、存檔／讀檔或 QA 驗收。舊劇情呈現圖另見
[歷史快照](docs/story-presentation/README.md)。

以 Godot 4.6.3 開啟此目錄的 `project.godot` 後執行。先用執行檔的
`--version` 確認版本；命令列可用 `--path <此專案目錄>` 啟動。
目前以 Windows 鍵盤滑鼠為主，沒有啟用手機觸控介面。

劇情續作已在原本六個主線委託下接入十二趟章節行動、25 個步驟：護送、按住 E 校準、搬運、據點防守與現場選擇。安全返村才保存本趟完成步驟，整章仍須達成原目標後按 J 一次交付；舊已承接委託沿用舊規則。NPC 會依目前趟次交代工作；J/K 可展開「本趟待帶回／已帶回」的現場紀錄，已完成的舊存檔不會被補造行動歷史。K 也能重看上次出征帶回或遺失的步驟，部分撤離會指出下趟續作；結局保留都心的姓名公開選擇。詳見 [故事與玩法](docs/GAME_DESIGN.md) 和 [本次返村與結局畫面](docs/return-consequences/README.md)。目前是來源整合及預置畫面檢視，完整遊玩、存讀檔與時間平衡尚未驗收。

## 操作

- WASD 移動；移動時按下 Shift 閃避，持續按住疾跑，兩者都消耗 EP；普通行走可回復 EP。
- 滑鼠瞄準；左鍵依目前快捷欄使用武裝，右鍵遠程快捷攻擊，Space 近戰。J/K 只開委託／手記。
- 1–4 快捷裝備；Q 切換；I 開啟人物裝備面板；Tab 瀏覽目前畫面的鍵盤焦點。
- E 與附近目標互動／推進對話，接線等行動依提示按住 E；M 區域地圖只供查看，走到實際閘門按 E 才出發或撤離；G 世界紀行；H 說明。
- C 工坊、J 委託、T 終端、K 回收者手記與武裝圖鑑。
- J 在野外可查閱；承接、交付需回村莊或公會。面板會列出目標、報酬與下一步。
- J 將必需條件與選讀線索分開列出，材料顯示庫存／本趟數量；G 的目前主線使用同一份條件。最後一趟完成後仍缺材料或 Boss 時，下一步會提醒先補齊或提早撤離。
- Esc 關閉面板／暫停選單；F5 存檔、F9 讀檔。
- 暫停選單會顯示儲存／讀取結果；野外存檔是當趟快照，成功返村才入庫。返回標題與離開不會自動儲存。有舊檔時開始新旅程會先確認，序章完成時才覆寫。
- 回收工具左鍵短暫標示附近物資，仍需靠近拾取或按 E 採集；彈藥格只顯示資訊，射擊才自動消耗。死亡回艙若失敗，按 Esc 選「重試回收機體」。

## 開發與驗證

[繁體中文開發導讀](docs/DEVELOPER_GUIDE.zh-TW.md) 說明環境、文件與驗證方式。
[AGENTS.md](AGENTS.md) 是英文技術規範唯一入口；[WORKFLOW.md](WORKFLOW.md)
定義開發流程；[AI_HANDOFF.md](AI_HANDOFF.md) 保存目前狀態。

```powershell
python -m venv .godot/qa-venv
& .godot/qa-venv/Scripts/python.exe -m pip install -r requirements-qa.txt
# 將 GODOT_BIN 設成已確認的 Godot 4.6.3 console 執行檔完整路徑
& .godot/qa-venv/Scripts/python.exe scripts/tools/run_qa.py --godot $env:GODOT_BIN --profile core
```

上例適用 Windows PowerShell。POSIX shell 可使用：

```sh
python3 -m venv .godot/qa-venv
. .godot/qa-venv/bin/activate
python -m pip install -r requirements-qa.txt
export GODOT_BIN="/path/to/godot"
python scripts/tools/run_qa.py --godot "$GODOT_BIN" --profile core
```

`visual` 執行實際繪圖截圖；`performance` 蒐集效能樣本；`all` 執行整合驗證。
QA 在隔離副本／存檔環境執行，輸出目錄由工具顯示；不重建素材、不覆寫玩家存檔。
視覺檢查需要可用的桌面與繪圖驅動；headless 不能驗收畫面。
